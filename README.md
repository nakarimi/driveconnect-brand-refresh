# Driveconnect Brand Refresh

Restyle the whole site to the DriveConnect app palette only. Background #FFF8F6, warm sections #FFF2EF, cards #FFFFFF and #FFEEEA, buttons and wordmark #D41E24, button hover #B9151A, chips #FFD8D8, headings #39252A, body text #8F767B, borders #F2DFDB. Font is Plus Jakarta Sans. The wordmark is Poppins extra bold in #D41E24. Remove any navy, black, or purple theme.
